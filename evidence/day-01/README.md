# Day 1 Evidence

This directory is reserved for sanitized Day 1 screenshots.

Before uploading AWS console screenshots, review them for information that does not need to be public, including AWS account IDs, account aliases, ARNs containing account IDs, email addresses, access keys, tokens, or other credentials.

- `01-dynamodb-incidents.png`
- `02-iam-putitem-least-privilege.png`
- `03-iam-policy-json-redacted.png`
